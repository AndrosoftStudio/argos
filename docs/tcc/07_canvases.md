# Canvases do projeto

## Business Model Canvas (BM Canvas)

| Bloco | Conteudo |
|---|---|
| Proposta de valor | Monitoramento automatico de EPIs por camera, com alertas em tempo real e baixo custo. |
| Segmentos de clientes | Industrias, construtoras, oficinas, logistica, escolas tecnicas e empresas com areas de risco. |
| Canais | Demonstracao direta, site, apresentacao para empresas, parcerias com consultorias de seguranca. |
| Relacionamento | Suporte tecnico, implantacao guiada, treinamento de uso e manutencao de modelos. |
| Fontes de receita | Assinatura mensal, taxa de implantacao, plano por camera, plano com API. |
| Recursos principais | Software, modelos de IA, cameras, backend, hub, conhecimento em desenvolvimento. |
| Atividades principais | Desenvolvimento, treinamento de modelos, suporte, melhoria de precisao, integracao com empresas. |
| Parcerias principais | SENAI, empresas piloto, tecnicos de seguranca, provedores cloud. |
| Estrutura de custos | Hospedagem, energia, dominio, suporte, hardware com GPU, tempo de desenvolvimento. |

## Project Model Canvas (PM Canvas)

| Area | Definicao |
|---|---|
| Justificativa | Fiscalizacao manual de EPIs e limitada e sujeita a falhas. |
| Objetivo SMART | Entregar ate a banca um prototipo funcional que detecta uso de EPI, reconhece funcionarios e exibe alertas em tempo real. |
| Beneficios | Prevencao de acidentes, reducao de risco, apoio a equipe de seguranca, demonstracao tecnica para TCC. |
| Produto | Sistema web com backend de IA, frontend, cadastro, camera, hub e API. |
| Requisitos | Camera, usuario autenticado, modelo YOLO, backend rodando, navegador moderno. |
| Stakeholders | Aluno, orientador, banca, SENAI, empresas que poderiam usar a solucao. |
| Equipe | Desenvolvedor principal, orientador e avaliadores. |
| Premissas | Ha camera disponivel; o modelo tem classes treinadas; o backend tem recursos suficientes. |
| Riscos | Baixa precisao, baixa taxa de FPS, ambiente escuro, dataset pequeno, hardware fraco. |
| Linha do tempo | Planejamento, implementacao, testes, documentacao, video, apresentacao. |
| Custos | Infra gratuita no prototipo; possivel custo com dominio/camera/hardware. |
| Entregas | Codigo, POC, slides, pitch, video, relatorio, canvases e requisitos. |

## Lean Canvas

| Bloco | Conteudo |
|---|---|
| Problema | Empresas nao conseguem verificar uso de EPI o tempo inteiro. |
| Clientes | Empresas com risco ocupacional e necessidade de fiscalizacao constante. |
| Proposta unica de valor | Cameras comuns viram um sistema de alerta de seguranca em tempo real. |
| Solucao | IA identifica pessoa, EPI ausente, funcionario e atividade basica. |
| Canais | Demonstracao, SENAI, visitas tecnicas, site, indicacao. |
| Receita | Assinatura, implantacao, suporte e API. |
| Custos | Cloud, hardware, manutencao, treinamento de modelos. |
| Metricas-chave | FPS, precisao, alertas corretos, tempo de resposta, disponibilidade. |
| Vantagem injusta | Prototipo adaptavel, custo baixo, conhecimento local e foco no contexto real do TCC. |
