# Vigilancia EPI - pacote do TCC

Projeto: sistema de vigilancia inteligente para identificar uso de EPI, reconhecer funcionarios e apoiar a seguranca do trabalho em tempo real.

Contexto academico:
- Instituicao: SENAI Lauro de Freitas - Bahia.
- Curso: Desenvolvimento de Sistemas.
- Periodo: 3o semestre de um curso de 4 semestres.
- Natureza: TCC com prototipo funcional, prova de conceito e apresentacao para banca.

Arquivos deste pacote:
- `01_pitch_banca.md`: pitch de elevador sem termos tecnicos.
- `02_pitch_video_prototipo.md`: roteiro do video do prototipo.
- `03_financeiro.md`: custos, precificacao e viabilidade.
- `04_documentacao_projeto.md`: documentacao tecnica e operacional.
- `05_relatorio_partes.md`: o que cada parte do sistema faz.
- `06_poc.md`: prova de conceito.
- `07_canvases.md`: BM Canvas, Project Model Canvas e Lean Canvas.
- `08_requisitos.md`: requisitos de software e hardware.
- `09_apresentacao_slides.md`: narrativa e texto dos slides.
- `10_barema_banca.md`: barema sugerido para avaliacao.
- `11_arquitetura_hub_tensorrt_api.md`: arquitetura multi-backend, TensorRT e API de integracao.

Mensagem central:
O Vigilancia EPI transforma cameras comuns em uma camada de prevencao, identificando em tempo real quando um trabalhador esta com ou sem os equipamentos obrigatorios, registrando evidencias e permitindo que empresas atuem antes do acidente.
